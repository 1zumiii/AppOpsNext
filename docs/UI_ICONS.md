# Main page icons

The four main pages use selected glyphs from `@phosphor-icons/core` 2.1.1,
Regular weight. The selected bottom navigation item uses the matching Fill
weight. The icon containers and their semantic colors are defined by AppOpsNext.

Source: https://github.com/phosphor-icons/core/tree/main/assets

Package archive: https://registry.npmjs.org/@phosphor-icons/core/-/core-2.1.1.tgz

Archive SHA-256: `313332be6190b724da24107addd781799b48bf76b13963f24501112ffe1baadd`

To regenerate the Android vectors from an extracted package:

```sh
python3 scripts/generate_phosphor_vectors.py /path/to/package/assets
```

The MIT license text is packaged at `app/src/main/assets/licenses/phosphor-icons.txt`.
